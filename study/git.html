Git Internals

Git 소스 코드(v2.56.0-rc1)를 직접 읽고 정리한 내부 동작 원리 — 객체 데이터베이스 · 인덱스 · 팩 파일 · 레퍼런스 · 머지 · 전송 프로토콜까지 바이트 단위로 해부합니다.

학습 주제 목록

  • 01 폴더 하나를 지우면 왜 역사가 통째로 사라질까 — .git 디렉토리 해부 완료
  • 02 같은 파일을 100번 커밋해도 용량이 안 늘어난다 — 내용 주소 지정 객체 DB 완료
  • 03 해시는 파일 내용만으로 만들어지지 않는다 — 느슨한 객체 바이트 해부 완료
  • 04 Git은 폴더를 어떻게 기억할까 — 트리 객체 · 모드 비트 · 정렬 규칙 완료
  • 05 커밋은 변경사항이 아니다 — 커밋 객체 · 태그 · DAG 완료
  • 06 스테이징 영역은 대체 어디에 있는가 — 인덱스(DIRC) 바이너리 포맷 완료
  • 07 1초 안에 두 번 고치면 Git이 못 알아챌까 — Racy Git과 stat 캐시 완료
  • 08 객체 수십만 개를 파일 하나로 — 팩 파일 포맷과 가변 길이 인코딩 완료
  • 09 Git은 diff를 저장하지 않는다더니 — 델타 압축의 copy/insert 명령 완료
  • 10 팩 안의 객체 하나를 어떻게 즉시 찾을까 — .idx v2 · .rev · MIDX 완료
  • 11 브랜치는 41바이트짜리 파일이다 — ref · packed-refs · reflog · 원자성 완료
  • 12 레퍼런스 86만 개를 어떻게 감당할까 — reftable 백엔드 완료
  • 13 git log는 어떤 순서로 커밋을 뱉을까 — 리비전 워크와 UNINTERESTING 완료
  • 14 조상인지 확인하는 데 왜 전부 안 뒤져도 될까 — commit-graph와 generation number 완료
  • 15 공통 조상은 하나가 아닐 수 있다 — paint_down_to_common 완료
  • 16 git diff는 대체 무엇을 최소화하는가 — Myers · histogram · 들여쓰기 휴리스틱 완료
  • 17 파일을 옮겼는데 Git이 어떻게 알았을까 — rename detection과 유사도 점수 완료
  • 18 충돌 마커는 누가 어떻게 그릴까 — 3-way 머지와 merge-ort 완료
  • 19 rebase는 커밋을 옮기지 않는다 — sequencer · todo list · patch-id 완료
  • 20 지운 커밋은 언제 진짜로 사라질까 — 도달 가능성 · prune · fsck 완료
  • 21 clone할 때 둘은 무슨 대화를 나눌까 — pkt-line · 프로토콜 v2 · 네고시에이션 완료

  • 23 100GB 리포를 몇 초 만에 clone하는 법 — 부분 클론 · 희소 체크아웃 · 희소 인덱스 완료
